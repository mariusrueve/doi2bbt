# Security policy

## Supported version

The deployed `v1` API and the current `main` branch receive security fixes.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email
[contact@doi2bbt.org](mailto:contact@doi2bbt.org) with:

- the affected endpoint or component;
- reproduction steps or a proof of concept;
- the expected impact; and
- any suggested mitigation.

Do not access other users' data, disrupt the public service, or exceed the
published rate limit while testing. You should receive an acknowledgement
within seven days.
